# Ejercicios de POO - Herencia y polimorfismo

Proyecto Java con dos ejercicios, cada uno en su propia carpeta y con su diagrama UML editable de Draw.io.

## Ejercicio 1: MaterialDigital
Clases: `MaterialDigital`, `LibroDigital`, `Audiolibro` y `Main`.

Ejecutar desde `Ejercicio1-MaterialDigital/src/`:
```bash
javac *.java
java Main
```

## Ejercicio 2: MedioPago
Clases: `MedioPago`, `Tarjeta`, `BilleteraVirtual` y `Main`.

Ejecutar desde `Ejercicio2-MedioPago/src/`:
```bash
javac *.java
java Main
```

## UML
El archivo `Ejercicios-POO-Polimorfismo-UML.drawio` contiene dos páginas: MaterialDigital y MedioPago. Se puede abrir y editar en https://app.diagrams.net/.

Requisito: Java JDK. No requiere bibliotecas externas.
